# M2 local EVM review candidate

**No deployment authorized. No production ABI freeze.** These contracts have not received independent engineering or contract-security review. Runtime Base capabilities remain unavailable.

Use Foundry **1.3.1**, Solidity **0.8.30**, optimizer 200 runs, via-IR, Cancun target, no CBOR metadata. The EVM target is a reproducibility setting, not proof of Base network compatibility. OpenZeppelin Contracts **5.4.0** is vendored as its exact transitive import closure with MIT license. `dependencies.json` records the npm archive SHA-256 and per-file hashes; no library file is modified. These version pins are not a claim that PactAgent has been audited.

From the repository root:

```sh
node scripts/check-evm-dependencies.mjs
node --import tsx scripts/m2-vectors.ts
forge test --root contracts/evm -vv
forge test --root contracts/evm --match-test testBenchmarkFullAndEquivalentPinnedClone -vvvv
forge build --root contracts/evm --sizes
```

`test/vectors.json` is generated by the TypeScript codec using `node --import tsx scripts/m2-vectors.ts --write` and checked by Solidity tests. It specifies local chain 31337 and synthetic addresses only. Changing it requires review, not regeneration to hide a mismatch. The EIP-712 domain version is `2-local-review-1`. Action nonces are fixed zero because each distinct action occurs once under state guards. There is no replaceable pending-action nonce or deadline extension.

`PactFactory` is the provisional full-constructor factory and checks chain 84532 and the published test token address. It has no owner, upgrade or withdrawal selector. This alone is NOT sufficient deployment verification: no registry activates its bytecode. Local tests use a clearly separated `LocalFactory` test harness on chain 31337 and a mock token. No script broadcasts or uses private keys outside deterministic in-memory test keys.

`PactEscrow` has constructor-only terms, exact both-party funding, arbitrary mutual split, signed dispute invocation, directly verified sorted EOA arbiter threshold and permissionless fallback. All transfers and terminal transitions revert atomically on token failures. ERC-1271 applies only to participants. EOA arbiters with deployed/delegated code are rejected at construction and verdict execution; no mutable verifier/rotation/recovery exists.

The clone benchmark uses the same core, full terms and two-arbiter storage initialization: full deployment 2,129,779 gas versus clone+atomic initialization 584,505 gas (excluding one-time implementation deployment). The clone implementation is initializer-locked; the local factory initializes clones atomically. The lifecycle suite and stateful invariants exercise both forms. Full deployment remains preferred provisionally to avoid external initializer/delegatecall complexity; no independent safety equivalence or finalized factory choice is claimed.

Generated ABI/bytecode is in ignored `out/`. Reproduce it with the pinned settings; ABI and creation/runtime template digests are recorded by `scripts/m2-contract-artifacts.mjs`. Immutable constructor values alter instance runtime code; template hashes cannot activate an instance. No live deployment addresses, deployment scripts or broadcast permissions are provided.

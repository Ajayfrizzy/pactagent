# M2 local EVM review candidate

**No deployment authorized. No production ABI freeze.** These contracts have not received independent engineering or contract-security review. Runtime Base capabilities remain unavailable.

Use Foundry **1.3.1**, Solidity **0.8.30**, optimizer 200 runs, via-IR, Cancun target, no CBOR metadata. The EVM target is a reproducibility setting, not proof of Base network compatibility. OpenZeppelin Contracts **5.4.0** is vendored as its exact transitive import closure with MIT license. `dependencies.json` records the npm archive SHA-256 and per-file hashes; no library file is modified. These version pins are not a claim that PactAgent has been audited.

From the repository root:

```sh
node scripts/check-evm-dependencies.mjs
node --import tsx scripts/m2-vectors.ts
forge test --root contracts/evm -vv
forge test --root contracts/evm --match-test testBenchmarkFullAndEquivalentPinnedClone -vvvv
forge build --root contracts/evm --sizes
```

`test/vectors.json` is generated by the TypeScript codec using `node --import tsx scripts/m2-vectors.ts --write` and checked by Solidity tests. It specifies local chain 31337 and synthetic addresses only. Changing it requires review, not regeneration to hide a mismatch. The EIP-712 domain version is `2-local-review-2`. Funding/mutual/arbitration use separate onchain cancellation epochs; dispute remains single-use nonce zero. Terms include interval policy/version. No deadline extension is possible. See the M2 design register for provisional authority and exact boundary semantics.

`PactFactory` is the provisional full-constructor factory and checks chain 84532 and the published test token address. It has no owner, upgrade or withdrawal selector. This alone is NOT sufficient deployment verification: no registry activates its bytecode. Direct PactEscrow construction enforces the same chain/issuer restriction. Local tests use clearly separated `LocalEscrow`/`LocalFactory` test harnesses on chain 31337 and a mock token. The opt-in backend integration harness broadcasts signed transactions only to loopback Anvil chain 31337, using ephemeral fixture keys. No public-network broadcaster is enabled.

`PactEscrow` has constructor-only terms, exact both-party funding, arbitrary mutual split, signed dispute invocation, directly verified sorted EOA arbiter threshold and permissionless fallback. All transfers and terminal transitions revert atomically on token failures. ERC-1271 applies only to participants. EOA arbiters with deployed/delegated code are rejected at construction and verdict execution; no mutable verifier/rotation/recovery exists.

The clone benchmark uses the same core, full terms and two-arbiter storage initialization: local full harness 2,488,411 gas versus clone+atomic initialization 630,726 gas (excluding one-time implementation deployment). The clone implementation is initializer-locked; the local factory initializes clones atomically. The lifecycle suite and stateful invariants exercise both forms. Full deployment remains preferred provisionally to avoid external initializer/delegatecall complexity; no independent safety equivalence or finalized factory choice is claimed.

Generated ABI/bytecode is in ignored `out/`. Reproduce it with the pinned settings; ABI and creation/runtime template digests are recorded by `scripts/m2-contract-artifacts.mjs`. Immutable constructor values alter instance runtime code; template hashes cannot activate an instance. No live deployment addresses, deployment scripts or broadcast permissions are provided.

```sh
RUN_LOCAL_EVM_TESTS=true LOCAL_EVM_PORT=18545 node --import tsx --test server/src/modules/base/local-evm.integration.test.ts
```

This requires DATABASE_URL/DIRECT_URL for the disposable DB, generated Prisma and
compiled Foundry fixtures. The test uses privileged Anvil fixture/snapshot controls;
it is not independent-provider or public Base evidence.
